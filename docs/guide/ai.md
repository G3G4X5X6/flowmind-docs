# AI 功能

FlowMind 是 AI-Native 安全平台：在独立 **AI 窗口**中提供多 Provider 对话，并通过工具调用参与抓包、重放、模糊测试、扫描与报告整理；具体动作在 Rust 运行时中确定性执行。

![AI-会话](/screenshots/AI-会话.png)

## 功能概览

| 功能 | 说明 |
|------|------|
| AI 对话 | 多 Provider、流式输出，可挂载流量上下文 |
| 工具调用 | 查询 Flow、Finding，驱动重放 / Fuzz / 扫描等 |
| MCP | 接入外部 MCP Server 扩展工具 |
| Skills | 通过 SKILL.md 能力包约束工具与提示 |
| 智能重放 | 会话与 Token 管理、差异对比、可选写入 Finding |
| 智能 Fuzz | 端点分析、策略建议、Payload 生成（执行需确认） |
| Engram 记忆 | 跨会话决策回忆与压缩摘要（在 AI 设置中配置） |

::: info 能力变更（2026-09-29）
知识库 / RAG、旧版安全记忆、Agent 分析面板与 Attack Map 已下线。当前以 **对话 + 工具 + Skills + Engram** 为主路径。
:::

## 打开 AI 窗口

点击主窗口标题栏 **AI** 按钮，打开第二窗口，包含：

| 视图 | 功能 |
|------|------|
| **对话** | 会话列表与聊天；可挂载流量、切换角色/模型 |
| **设置** | 模型、Provider、MCP、Engram、动态工具、Agent、Skills、高级选项 |

其他入口：

- **上下文预览**：会话右上角「上下文」，查看系统提示构成与字符预算
- **运行轨迹**：展开模型推理、工具调用与系统事件
- **确认卡**：需审批的工具动作在对话末尾请求允许/拒绝（一次一张）

AI 相关配置在 **AI 窗口 → 设置** 中维护（与主窗口 **设置** 共用本地配置文件）。主窗口 **设置** 仅包含通用、代理、浏览器、证书与关于。

## 配置模型与 Provider

1. 打开 **AI 窗口 → 设置 → 模型与对话**，选择活跃 Provider 与模型
2. 在 **Provider** 分区填写 API Key、Base URL 与模型列表
3. 按需配置 **MCP Servers**、**Skills**、**Engram** 等
4. 点击 **保存设置**

更多字段说明见 [设置](./settings.md#ai-配置)（与 AI 窗口设置对应）。

## 发送 Flow 到 AI

1. 在转发器选择请求
2. 右键 → **发送到 AI**
3. 在会话中继续提问，AI 会结合已挂载的 Flow 分析

## 工具调用

AI 可在对话中**自动调用应用内置能力**（如查询流量、查看发现、解码令牌、触发扫描等），无需手动复制数据。具体可用能力取决于当前 Skill、角色与工具权限，以界面展示为准。

在会话中用自然语言描述目标即可，例如：

- 「分析当前项目里有哪些 API 端点」
- 「总结最近的高危发现」
- 「解读这条请求里的 JWT 载荷」

## 智能重放

AI 可驱动**智能重放**：维护认证上下文、通过代理通道真实发包、对比基线与重放响应，并在确认后可选写入 Finding。

典型用法（在对话中说明意图即可）：

- 重放指定 Flow 并对比响应差异
- 检查 Token / 会话是否仍有效
- 验证不同身份下的访问结果

::: tip
重放相关的 Token 与会话**默认仅保存在内存**，重启应用后需重新导入凭证。
:::

## 智能 Fuzz

AI 可分析端点结构、建议策略（如 IDOR、认证绕过、注入类场景）并生成 Payload；**实际开跑 Fuzz 任务**通常需要你在对话中确认，或在 **模糊器** 页面手动执行。

## 授权与安全边界

主动测试经过运行时策略控制，而不仅依赖提示词：

| 机制 | 说明 |
|------|------|
| 工具权限 | 按规则允许、询问或拒绝；需确认时弹出确认卡 |
| 项目范围 | 重放、改包、序列、Fuzz、主动扫描等目标须落在当前项目的代理域名范围内 |

项目范围对应 **项目设置 → 代理与限制** 中的包含/排除域名。超出范围时工具会返回策略拒绝，AI 会说明原因。

向外部 LLM 或 MCP 发送的内容取决于你的 Provider 与挂载的上下文；敏感环境请使用本地模型或企业网关。

## 最佳实践

1. **先让 AI 了解目标**：例如「分析当前流量，说明接口结构与认证方式」
2. **组合插件与 AI**：被动/主动规则覆盖已知模式，再用重放与 Fuzz 验证
3. **控制上下文成本**：使用「上下文」面板查看预算，必要时开新会话
4. **沉淀结论**：在报告页整理发现与素材

## 常见问题

### 智能 Fuzz 会自动执行吗？

分析类步骤可由 AI 触发；真正执行 Fuzz 一般需确认或在模糊器页手动运行。

### 旧版知识库 / Attack Map 去哪了？

上述能力已于 2026-09-29 下线。请使用对话工具链与 Engram（如已启用）完成当前工作流。
